# 🧩 Chrome Extension Scraper cho Google Looker Studio

Tiện ích mở rộng Chrome (Manifest V3) giúp trích xuất trực tiếp dữ liệu từ báo cáo Looker Studio mà bạn đang xem trên trình duyệt Chrome (không lo vấn đề login/xác thực Google).

---

## 🛠️ Hướng dẫn Cài đặt vào Chrome (Chỉ làm 1 lần)

1. Mở trình duyệt **Google Chrome**.
2. Truy cập vào trang quản lý tiện ích: `chrome://extensions/`
3. Bật công tắc **Chế độ dành cho nhà phát triển (Developer mode)** ở góc trên bên phải.
4. Nhấn vào nút **Tải tiện ích đã giải nén (Load unpacked)** ở góc trên bên trái.
5. Chọn thư mục tiện ích:
   `/Users/nguyenduythanh/Documents/ndtsoft/BaoCaoAnCa/chrome_extension`

---

## ⚡ Hướng dẫn Sử dụng

1. Mở trang báo cáo Looker Studio của bạn trên Chrome (đã đăng nhập tài khoản Google):
   `https://datastudio.google.com/u/0/reporting/bb32f8f7-b37f-4a9b-b222-c1f261bad785/page/p_8szgaxg19c`
2. Nhấp vào biểu tượng Tiện ích mở rộng (Extension icon 📊) ở góc trên thanh công cụ Chrome.
3. Bấm **⚡ Trích xuất Dữ liệu (Scrape Data)**.
4. Nhấn **📥 Tải File Excel (.xlsx)** hoặc **📄 Tải File CSV (.csv)** để lưu file về máy.
